# Hybrid Automation Framework

## Project Overview
A Selenium WebDriver automation testing framework developed using Java, TestNG and Maven.

## Technologies Used
- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)
- Extent Reports

## Framework Features
- Page Object Model
- Reusable methods
- TestNG annotations
- Explicit Waits
- Screenshot Capture
- Test Execution Reports

## Modules
- Login
- Product
- Shopping Cart

## How to Run
1. Clone the repository.
2. Import into Eclipse as an Existing Maven Project.
3. Update Maven dependencies.
4. Run testng.xml as TestNG Suite.
5. Check the execution results.
